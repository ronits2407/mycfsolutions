## Problem Statement

<div class="header"><div class="title">D. Copy String</div><div class="time-limit"><div class="property-title">time limit per test</div>2 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>Given two strings $$$s$$$ and $$$t$$$ of length $$$n$$$, you aim to transform $$$s$$$ into $$$t$$$ through a series of the following operations:</p><ul> <li> Construct a new string $$$s'$$$ of length $$$n$$$,where $$$s'_1=s_1$$$. For each $$$1  \lt  i \le n$$$, $$$s'_i$$$ can be either $$$s_i$$$ or $$$s_{i-1}$$$. Then replace $$$s$$$ with $$$s'$$$. </li></ul><p>Your task is to achieve this transformation using <span class="tex-font-style-bf">the minimum number of operations</span>. You also need to output the solution by printing the constructed string $$$s'$$$ after each operation. If the transformation cannot be achieved in less than or equal to $$$k_{\mathrm{max}}$$$ operations, output <span class="tex-font-style-tt">-1</span>.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. The first line contains the number of test cases $$$t$$$ ($$$1 \le t \le 10^4$$$). The description of the test cases follows. </p><p>The first line of each test case contains two integers $$$n$$$, $$$k_{\mathrm{max}}$$$ ($$$1 \le n \cdot k_{\mathrm{max}} \le 10^6$$$) — the length of two strings and the maximum number of operations that can be used.</p><p>The second line of each test case contains one string $$$s$$$ of length $$$n$$$.</p><p>The third line of each test case contains one string $$$t$$$ of length $$$n$$$.</p><p>It is guaranteed that the sum of $$$nk_{\mathrm{max}}$$$ over all test cases does not exceed $$$10^6$$$.</p><p>It is guaranteed that both $$$s$$$ and $$$t$$$ consist of lowercase Latin letters.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case: </p><ul> <li> If you cannot achieve the transformation in less than or equal to $$$k_{\mathrm{max}}$$$ operations, simply output <span class="tex-font-style-tt">-1</span> in one line. </li><li> Otherwise, on the first line, output one integer $$$k \le k_{\mathrm{max}}$$$ — the minimum number of operations. Then $$$k$$$ lines follow, each line contains one string of length $$$n$$$ — the string after each operation. </li></ul><p>If there are multiple solutions, output any.</p></div><div
